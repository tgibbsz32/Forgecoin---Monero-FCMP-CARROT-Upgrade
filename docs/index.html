01 / TECHNOLOGY

Built to be run by you.

ForgeCoin is developed in the open, with private transactions and a local-first approach to participating in the network.

DEVELOPMENT ROADMAP

Native first. Interoperability later.

ForgeCoin launches as an independent private Proof-of-Work network. Native trading and optional Solana utilities are research milestones, not active products or promised launches.

PHASE 1 / PRE-LAUNCH

Validate the native network

Resolve genesis, verify mining rewards and difficulty, complete cross-platform builds, wallet testing, security review and public infrastructure.

PHASE 2 / ADOPTION

Mining and development funding

Support independent miners and pools. Explore an optional development treasury funded by voluntary contributions and actual project revenue, never a genesis premine.

PHASE 3 / RESEARCH

Native FRG trading

Evaluate noncustodial peer-to-peer trades, independently reviewed atomic swaps and third-party routes to USDC, ETH and SOL. No provider or liquidity is currently confirmed.

PHASE 4+ / OPTIONAL

Solana and privacy applications

Research a 1:1 user-deposit-backed SPL representation, audited bridge, transparent reserves, and later DeFi utilities. Not required for L1 launch.

Roadmap items depend on security validation, operational resources and adoption. No swaps, wrapped token, yield program or bridge are currently available. Read the full development roadmap.
