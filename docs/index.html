ForgeCoin (FRG) is a Monero-derived, privacy-preserving proof-of-work network built around CPU-accessible mining and self-operated infrastructure.

Bootstrap-stage software. The network has limited independent hash power, has not been independently audited, and is not recommended for substantial value.

01 / TECHNOLOGY

Built to be run by you.

ForgeCoin is developed in the open, with private transactions and a local-first approach to participating in the network.

◇

Privacy-preserving transactions

Derived from Monero's privacy-focused protocol. Privacy claims and fork-specific changes require independent assessment.

⌘

CPU-accessible proof of work

RandomX makes general-purpose processors the primary mining hardware target.

⬡

Operate your own node

Use local node and wallet software without depending on a hosted custodial wallet or explorer.

Never download wallets from unsolicited links. Verify checksums for any published binary. Back up and protect recovery seeds. Do not expose wallet RPC or unrestricted daemon RPC to the internet.
