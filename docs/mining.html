ForgeCoin mining guide

ForgeCoin uses RandomX CPU-oriented proof of work with a target block interval of 120 seconds. Solo mining is possible, but rewards are uncertain and depend on network difficulty and your effective hashrate.

1. Prepare your system

Review the source status and requirements. ForgeCoin currently has no validated public binary release; build from audited source or wait for an official release.

Build documentation ↗

2. Start and synchronize a node

New nodes require at least one existing ForgeCoin peer. Use the desktop Node tab or the daemon's --add-peer host:19480 argument with a trusted peer address. Replace host with a real peer hostname or IP.

3. Secure your wallet

Create or restore a wallet locally and make a protected backup of its recovery seed. Never send that seed to mining pools, websites, or support contacts.

4. Begin solo mining

After your node is synchronized, use the Tauri desktop solo-mining interface with your wallet. The desktop also supports user-configured compatible pools through XMRig. Official-pool selection and end-to-end payout verification are planned; no public project-pool endpoint is endorsed here.

Official pool and monitoring roadmap

The official native FRG pool is planned with a 1% operator fee on eligible pooled rewards; payout transaction costs are separate. Solo mining has no project-pool fee. Verified official-pool integration in Tauri, the pool website/dashboard and a standalone Pool Observer remain planned work. The online blockchain explorer also requires completion and public deployment verification.

Offline tests, mature payouts with two test miners, reorg/recovery and load tests, independent security review, private staging and controlled beta must precede public rollout. Read the implementation plan.

Need more details?

Check the repository's current desktop README, source-recovery notes, and security guidance. Network bootstrapping, synchronization, reorganization behavior and fresh-build packaging need further testing before broad adoption.
